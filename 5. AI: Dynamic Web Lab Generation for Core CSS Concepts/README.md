# AI: Dynamic Web Lab Generation for Core CSS Concepts

## Overview

This task demonstrates the use of AI to generate interactive web development labs for learning core CSS concepts. The labs were created using Gemini Canvas and use HTML, CSS, and JavaScript in single-file web applications.

## Files

### 1. refined-box-model.html

This file contains the refined CSS Box Model and Display interactive lab. It allows users to adjust the width, height, corner radius, padding, border width, and margin independently for the top, right, bottom, and left sides. It also allows the display property to be changed and provides real-time visual feedback.

### 2. flexbox-grid-playground.html

This file contains the interactive Flexbox and Grid playground. It allows users to change container properties such as display, flex-direction, justify-content, align-items, and grid-template-columns and see the layout update in real time.

## AI Tool Used

Gemini with Canvas was used to generate and refine the interactive HTML, CSS, and JavaScript applications through sequential prompting.

## Learning Focus

The task focuses on understanding the CSS Box Model, display behavior, Flexbox, Grid, and the use of iterative AI prompting to develop and refine interactive software.
